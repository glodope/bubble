# Пузырёк

Мобильная аркада, где пузырёк в газировке пытается подняться как можно выше, не задев лёд, лимон и прочий мусор в стакане. Нажимаешь влево/вправо — пузырёк прилипает к стенке, отпускаешь — летит к другой. Чем выше, тем быстрее.

**Живая версия:** [https://твой-ник.github.io/пузырёк](https://твой-ник.github.io/пузырёк) — работает через GitHub Pages прямо из репозитория.

## Управление

- **Тап левой половины экрана** — рывок влево
- **Тап правой половины экрана** — рывок вправо
- **A / ← / Пробел** — влево (для клавиатуры)
- **D / →** — вправо

## Что внутри

- 4 типа препятствий: кубики льда, дольки лимона, соломинки, листья мяты. Спавнятся рандомно, чем дальше — тем чаще.
- Монетки за которые покупаются скины. Скины меняют цвет пузырька и фон.
- 12 скинов: от обычного мыла до плазмы и тени. Есть за монеты, есть за прогресс.
- Прогресс, рекорд и открытые скины сохраняются в `localStorage`.
- Звуки на Web Audio API — щелчки прилипания, лопание, звон монет. Можно выключить.
- Вибрация на мобильных (если браузер даёт).

## Запуск

Просто открыть `index.html` в браузере. Работает оффлайн, ничего собирать не надо. Для мобильного лучше добавить на экран как PWA — в `manifest` всё прописано.

## Стек

Чистый JS + Canvas 2D. Никаких фреймворков, никаких сборщиков. Работает везде, где есть тач и `requestAnimationFrame`.
